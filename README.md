# Simulated Temperature Logger using Python

This project simulates an IoT temperature sensor system using Python. It generates random temperature readings and logs them with timestamps.

## 📌 Features
- Simulates 10 temperature readings using `random`
- Logs data to a CSV file
- Also saves data in JSON format
- Alerts if temperature > 30°C
- Generates a graph of all readings using `matplotlib`

## 📁 Output Files
- `temperature_log.csv` – tabular temperature log
- `temperature_log.json` – JSON version of the data
- `temperature_plot.png` – line graph of readings

## 🛠 Tools Used
- Python
- CSV, JSON
- matplotlib
- datetime
- time
- random
